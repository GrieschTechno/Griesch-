# AUDIOCORE DARK BASS

AUDIOCORE AudioCoreTools — VST3 + Standalone development prototype.

This repository contains the source code and automated Windows build workflow for AUDIOCORE DARK BASS.

Status: development prototype; Windows build and FL Studio compatibility still require verification.

License: GPL-3.0-or-later for project source. JUCE remains subject to its own license terms.


## Build status
Windows builds are automated through GitHub Actions. The VST3 package is published as the workflow artifact `AUDIOCORE-DARK-BASS-Windows` after a successful build.
